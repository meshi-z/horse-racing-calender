# JRA（日本中央競馬会）データ仕様書 (JRA Data Specifications)

本ドキュメントは、JRA（日本中央競馬会）の重賞レース（G1, G2, G3, J.G1, J.G2, J.G3）に関するデータソース、パースロジック、タイムゾーン、および確定発走時刻自動取得バッチの技術仕様書です。

---

## 1. データソース一覧

| 項目 | ソースURL / 取得先 | 用途 |
| :--- | :--- | :--- |
| **重賞レース一覧** | `https://www.jra.go.jp/datafile/seiseki/replay/{YYYY}/jyusyo.html` | レース名、グレード、開催日、競馬場、距離、馬場、出走条件、斤量 |
| **公式カレンダー** | JRA公式サイト提供の公式 `.ics` / ZIP アーカイブ | 年間開催日程、レース日割 |
| **出馬表・確定時刻** | JRA公式「今週の注目レース」および出馬表詳細ページ | 開催週の出走馬確定および正式発走時刻（JST） |
| **過去実績マスタ** | `src/data/jra_past_times_2026.json` | 開催済み過去重賞の実績確定発走時刻 |

---

## 2. タイムゾーン & 発走時刻仕様

- **タイムゾーン**: 日本標準時（JST: UTC+9、夏時間なし）
- **UTC変換**: `JST - 9時間 = UTC`
- **年間初期推定発走時刻（マスタデフォルト値）**:
  - 関東開催（東京・中山）平地重賞: `15:45` JST（UTC `06:45`）
  - 関西開催（京都・阪神）平地重賞: `15:40` JST（UTC `06:40`）
  - ローカル・北海道開催（札幌・函館・福島・新潟・中京・小倉）: `15:35` JST（UTC `06:35`）
  - 障害重賞（J.G1〜J.G3）: `13:50`〜`14:45` JST 前後

---

## 3. データ生成 & パースロジック (`scripts/parse-races.ts`, `scripts/lib/jra-calendar.ts`)

1. **JRAカレンダーICSダウンロード & 展開**:
   - JRA公式サイトから年間開催カレンダーZIPを取得し、ICSファイルを抽出。
2. **重賞一覧HTML解析**:
   - `jyusyo.html` をパースし、レース基本情報と突合。
3. **ID採番ルール**:
   - 書式: `{YYYY}-jra-{grade_code}-{index}`（例: `2026-jra-g1-01`）
4. **グレード体系**:
   - 平地: `G1`, `G2`, `G3`
   - 障害: `J.G1`, `J.G2`, `J.G3`

---

## 4. 確定発走時刻自動取得 (`JraRaceTimeFetcher`)

- **実装ファイル**: `scripts/lib/jra-syutsuba.ts`, `scripts/update-race-times.ts`
- **対象ウィンドウ**: 基準日（木曜〜翌月曜）の開催予定レース
- **取得契機**: 木曜夕方（枠順確定前）および金曜昼前（出馬表確定時）
- **照合ルール**: 開催日、競馬場名、レース名の一致により `public/data/races.json` の `start_time` を更新し `is_time_confirmed: true` を設定。
