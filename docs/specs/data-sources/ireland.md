# アイルランド競馬（HRI / Sporting Life）データ仕様書 (Ireland Data Specifications)

本ドキュメントは、アイルランド競馬（Horse Racing Ireland: HRI統轄、IFHA Part I平地全67重賞競走、および主要障害重賞全31競走: パンチェスタウンフェスティバル全G1、ダブリンレーシングフェスティバル全G1、アイリッシュグランドナショナル等計98競走）に関するデータ仕様書です。

---

## 1. 基本メタ情報 (Metadata)

| 項目 | 設定値 / 仕様 | 備考 |
| :--- | :--- | :--- |
| **国コード (`country_code`)** | `"IE"` | ISO 3166-1 alpha-2 |
| **主催者コード (`organization`)** | `"hri"` | `Organization` 型識別子 |
| **原語・対応言語 (`languages`)** | `ja`, `en`, `fr`, `zh` | 日本語通称、英語正式名、仏語、繁体字中国語 |
| **レースID採番ルール (`id`)** | `{YYYY}-ie-{grade}-{index}` | 例: `2026-ie-g1-01`, `2026-ie-g1-27` (パンチェスタウンGC) |
| **格付け体系 (`grades`)** | `G1`, `G2`, `G3` | IFHA Part I 平地国際重賞（全67競走）およびHRI Jump Pattern 障害重賞（全31競走） |
| **マスタファイルパス** | `src/data/ireland_race_master.json` | 日英仏中辞書、主要競馬場マスタ、推定発走時刻 |
| **生成・ビルドモジュール** | `scripts/lib/ireland-races.ts`, `scripts/parse-races.ts` | IFHA Part I・HRI Jump Patternと公式スケジュールを統合 |

## 3. タイムゾーン & 発走時刻仕様 (Timezone & Schedule)

- **現地タイムゾーン**:
  - 冬時間: グリニッジ標準時（GMT: UTC+0）
  - 夏時間: アイルランド標準時（IST: Irish Standard Time, UTC+1）
- **夏時間（IST）規則**:
  - 適用期間: 3月最終日曜日 〜 10月最終日曜日（EU共通規則）
- **UTC変換式**:
  - 夏時間（IST）: `IST - 1時間 = UTC`（日本時間 JST 比: `UTC + 9時間 = JST`、時差 8時間）
  - 冬時間（GMT）: `GMT = UTC`（日本時間 JST 比: `UTC + 9時間 = JST`、時差 9時間）
- **標準推定発走時刻（マスタ初期値）**:
  - 平地主要競走（愛ダービー、愛チャンピオンS等）: 現地 15:30〜16:15（夏時間: UTC `14:30`〜`15:15` / JST `23:30`〜`00:15`）
  - パンチェスタウンフェスティバル: 現地 15:15〜18:35（IST: UTC `14:15`〜`17:35` / JST `23:15`〜`02:35`）
  - ダブリンレーシングフェスティバル: 現地 13:05〜15:25（GMT: UTC `13:05`〜`15:25` / JST `22:05`〜`00:25`）
  - 通常重賞競走: 現地 13:30〜17:00 前後

### 4.2 馬場種別 (`track_type`) & 特殊競走仕様
- **採用馬場種別**:
  - `turf` (芝): カラ、レパーズタウン、ネース等の天然芝コース
  - `aw` (オールウェザー): ダンドーク競馬場の全天候ポリトラックコース
  - `obstacle` (障害): ナショナルハント競走（チェイス / スティープルチェイス、ハードル、バンパー）
    - **パンチェスタウンフェスティバル (4月下旬〜5月上旬)**: アイルランド障害の春の祭典（全12G1: パンチェスタウンゴールドC、チャンピオンチェイス、チャンピオンハードル等）
    - **ダブリンレーシングフェスティバル (1月下旬〜2月上旬)**: レパーズタウン競馬場の冬の祭典（全8G1: アイリッシュゴールドC、アイリッシュチャンピオンハードル、ダブリンチェイス等）
    - **フェアリーハウス・イースターフェスティバル (4月復活祭)**: 伝統の大一番**アイリッシュグランドナショナル**（Premier Handicap / `grade: G3` / 5834m）、ウィローウォームゴールドカップ等
    - **クリスマスフェスティバル (12月下旬)**: サヴィルズチェイス、クリスマスハードル等レパーズタウン・リムリック開催の主要G1群

## 5. 確定発走時刻自動取得バッチ仕様 (RaceTimeFetcher)

- **プロバイダー名**: `IeRaceTimeFetcher`
- **実装ファイル**: `scripts/lib/ie-syutsuba.ts`, `scripts/update-race-times.ts`
- **対象開催ウィンドウ**: 基準日（JST）から直近7日間の開催予定レース（`getIeUpcomingWindowRange`）
- **CLI実行コマンド**: `npm run data:update-times:ie`（または `--org hri`）
- **定期実行スケジュール**:
  - 毎日 21:30 JST（現地午後・出馬表および確定発走時刻取得枠）
- **名寄せ・照合アルゴリズム**:
  - `ieRaceMatches` / `ieCourseMatches` により、レース名に含まれるスポンサー冠名、ステークス略称をトークン化して照合。
  - 夏時間判定（`isBritishSummerTime` と同一規則）により、日付から正確に GMT / IST を判別して UTC 変換。
