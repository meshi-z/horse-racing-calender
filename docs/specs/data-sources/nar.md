# NAR（地方競馬・ばんえい競馬）データ仕様書 (NAR Data Specifications)

本ドキュメントは、NAR（地方競馬全国協会）のダートグレード競走（Jpn1〜Jpn3、国際G1）、南関東重賞（S1〜S3）、全国各地区地方重賞、およびばんえい競馬に関するデータ仕様書です。

---

## 1. データソース一覧

| 項目 | ソースURL / 取得先 | 用途 |
| :--- | :--- | :--- |
| **年間重賞スケジュール** | `https://www.keiba.go.jp/gradedrace/schedule_{YYYY}.html` | NAR全地区重賞およびばんえい重賞の年間一覧 |
| **ダートグレード競走日程・確定時刻** | `https://www.keiba.go.jp/dirtgraderace/{YYYY}/racelist/` | ダートグレード・国際G1の確定発走時刻 |
| **地方各場当日出馬表** | `https://www.keiba.go.jp/KeibaWeb/TodayRaceInfo/RaceList?k_raceDate={YYYY/MM/DD}&k_babaCode={Code}` | 全地方競馬場・全重賞の当日確定発走時刻 |
| **補完マスタ & 辞書** | `src/data/nar_race_master.json` | 英語表記辞書、競馬場推定時刻、未登録レースローマ字変換 |

## 3. グレード標準化ルール

NAR公式スケジュール内の表記を以下の統一コードに正規化します。
1. **国際G1**: 東京大賞典等 $\rightarrow$ `G1`
2. **ダートグレード競走**: `Jpn1`, `Jpn2`, `Jpn3`
3. **南関東重賞**: `S1`, `S2`, `S3`
4. **各地区独自重賞**: 重賞1〜3、H1〜H3、M1〜M3、BG1〜BG3 等 $\rightarrow$ `local_grade`（地方重賞 / Regional Grade）

## 4. 確定発走時刻自動取得 (`NarRaceTimeFetcher`)

- **実装ファイル**: `scripts/lib/nar-syutsuba.ts`, `scripts/update-race-times.ts`
- **対象ウィンドウ**: 基準日から直近7日間の開催予定レース
- **スクレイピング戦略**:
  1. ダートグレード競走年間日程ページから確定時刻を取得。
  2. 南関・地方重賞・ばんえいは開催当日および直前の `RaceList` を各馬場コードでピンポイント取得。
- **名寄せルール**: `cleanNarRaceName` により、レース名に含まれる「第〇回」「[GDJ]」「（Jpn1）」等の修飾子を除去して照合。
