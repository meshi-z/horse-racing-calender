# NAR（地方競馬・ばんえい競馬）データ仕様書 (NAR Data Specifications)

本ドキュメントは、NAR（地方競馬全国協会統轄、ダートグレード競走、南関東重賞、全国各地区地方重賞、およびばんえい重賞）に関するデータ仕様書です。

---

## 1. 基本メタ情報 (Metadata)

| 項目 | 設定値 / 仕様 | 備考 |
| :--- | :--- | :--- |
| **国コード (`country_code`)** | `"JP"` | ISO 3166-1 alpha-2 |
| **主催者コード (`organization`)** | `"nar"` | `Organization` 型識別子 |
| **原語・対応言語 (`languages`)** | `ja`, `en` | 日本語およびヘボン式/カタカナ辞書英名 |
| **レースID採番ルール (`id`)** | `{YYYY}-nar-{grade_code}-{index}` | 例: `2026-nar-jpn1-01`, `2026-nar-s1-01` |
| **格付け体系 (`grades`)** | `G1`, `Jpn1`〜`Jpn3`, `S1`〜`S3`, `local_grade` | 国際G1、ダートグレード、南関、地区重賞 |
| **マスタファイルパス** | `src/data/nar_race_master.json` | 日英辞書、ヘボン式例外、競馬場デフォルト発走時刻 |
| **生成・ビルドモジュール** | `scripts/lib/nar-schedule.ts`, `scripts/parse-races.ts` | 公式スケジュールHTMLスクレイパーと統合 |

## 2. データソース一覧 (Data Sources)

| 分類 | ソース元 / URL | 取得形式 | 用途 |
| :--- | :--- | :--- | :--- |
| **年間日程 / カレンダー** | `https://www.keiba.go.jp/gradedrace/schedule_{YYYY}.html` | HTML | 年間重賞実施スケジュール（全地区・ばんえい） |
| **格付け・出走条件** | NAR公式競走体系・出走条件規定 | Web / PDF | グレード、出走資格、斤量、距離、馬場 |
| **ダートグレード確定時刻** | `https://www.keiba.go.jp/dirtgraderace/{YYYY}/racelist/` | HTML | ダートグレード競走年間日程・公式確定時刻 |
| **地方各場当日出馬表** | `https://www.keiba.go.jp/KeibaWeb/TodayRaceInfo/RaceList?k_raceDate={YYYY/MM/DD}&k_babaCode={Code}` | HTML | 全地方競馬場の当日確定発走時刻 |
| **過去実績補完データ** | `scripts/backfill-nar-past-times.ts` | スクリプト | 過去NAR全重賞の出馬表アーカイブバックフィル |

## 3. タイムゾーン & 発走時刻仕様 (Timezone & Schedule)

- **現地タイムゾーン**: 日本標準時（JST: UTC+9）
- **夏時間（DST）規則**: なし（通年固定）
- **UTC変換式**: `JST - 9時間 = UTC`
- **標準推定発走時刻（マスタ初期値）**:
  - ナイター開催場（大井・川崎・船橋・門別・高知・佐賀等）: `20:05`〜`20:15` JST（UTC `11:05`〜`11:15`）
  - 昼間開催場（浦和・盛岡・水沢・金沢・笠松・園田・姫路等）: `16:30` JST（UTC `07:30`）
  - ばんえい競馬（帯広重賞）: `19:30` JST（UTC `10:30`）

### 4.2 馬場種別 (`track_type`) & 特殊競走仕様
- **採用馬場種別**:
  - `dirt` (ダート): 地方競馬平地競走の標準コース（盛岡の平地重賞含む）
  - `banei` (ばんえい): 帯広競馬場での直線200m（2つの障害坂）のそり重量競走
- **特殊条件**:
  - ばんえい重賞は競走距離を一律 `200`（m）として整数格納。

## 5. 確定発走時刻自動取得バッチ仕様 (RaceTimeFetcher)

- **プロバイダー名**: `NarRaceTimeFetcher`
- **実装ファイル**: `scripts/lib/nar-syutsuba.ts`, `scripts/update-race-times.ts`
- **対象開催ウィンドウ**: 基準日（JST）から直近7日間の開催予定レース（`getNarUpcomingWindowRange`）
- **CLI実行コマンド**: `npm run data:update-times -- --org nar`
- **定期実行スケジュール**:
  - 毎日 07:30 JST（昼間・ナイター出馬表・発走確定枠）
  - 平日 12:30 JST（昼間開催発走直前枠）
  - 平日〜土曜 17:30 JST（ナイター開催発走直前枠）
- **名寄せ・照合アルゴリズム**:
  - `cleanNarRaceName` により、レース名に含まれる「第〇回」「[GDJ]」「（Jpn1）」等のグレード表記揺れを除去し、対象競馬場の馬場コードページ（`RaceList`）から確定発走時刻を突合。
