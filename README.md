## Diretory Structure

主要なディレクトリの役割は次のとおりです。

```text
src/
|- components/
|  |- ui/       # shadcn UI由来の汎用UIプリミティブ
|  `- shared/   # 複数機能で利用する合成コンポーネント
|- features/    # 機能・ドメイン固有の実装
|- hooks/       # 複数機能で利用する React Hooks
|- libs/        # UIに依存しない共通処理
`- styles/      # グローバルスタイルとテーマ
```

* 実際のファイル構造を正本とする。
* 新しいトップレベルディレクトリを追加した場合は、この説明を更新する。
* ツリーには主要ディレクトリだけを記載します。ファイル単位の一覧はすぐ古くなるため不要です。
